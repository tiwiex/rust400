# Story Template

Use this template when adding or refining a Rust/400 user story. Keep the story ID stable across the story file, branch name, pull request, build log, and supporting evidence.

## Header

- Story ID: `US-NNN-NN`
- Title: concise action-oriented title
- Epic: `EPIC-NNN`
- State: Proposed / Ready / In progress / In review / Done / Blocked

## Story statement

**As a** <user or contributor persona>, **I want** <capability or outcome> **so that** <value or reason>.

## Traceability

- Requirements: `FR-NNN`, `NFR-...`, product goal, or PRD section
- Priority: Must / Should / Could / Won't
- Dependencies: story IDs, ADRs, or `None`
- Planned branch: `story/us-nnn-nn-short-description`
- Planned build log: `YYYY-MM-DD-us-nnn-nn-short-description.md`
